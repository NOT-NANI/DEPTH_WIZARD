Unavailable on this backend. GeoTIFF input/export and DEM processing need Rasterio, which is not installed. Install with ./venv/bin/python -m pip install rasterio and restart the backend.

An ordinary PNG/JPG has no CRS or map transform, so the DEM can only be used on a same-sized pixel grid that you confirm is aligned. A DSM is DEM + estimated height; both error sources propagate. DEM use requires a metre-based height interpretation.

Inspect terrain structure from a single image

Add an RGB image, choose how heights are interpreted, and DepthWizard produces a unitless relative-depth grid plus a separately labelled height surface you can inspect pixel-by-pixel in 2D and 3D.
